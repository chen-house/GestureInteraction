说明
右手 · 特雷门琴（屏幕右半边）
音色分两家，行为不同：
敲击类（手碟 / 卡林巴 / 木琴 / 电钢）：捏一下＝敲
一下，之后自己衰减。按住没有额外意义，没有滑音
持续类（玻璃 / 柔和）：捏住＝一直响，手移动＝滑音

拇指和食指捏上 → 出声，松开 → 停
捏一下放 = 一个点音；捏住 = 长音，
捏着的时候手还能移动音高，那就是滑奏
同一个音连着弹两下（谱上的 3 3）＝捏两下
跳进（5 到 1'）＝松手、移过去、再捏。松手之后
音高就不跟手了，中间的音一个都不会响
捏住不放横着滑＝滑音，那时候才会经过中间的音
上下 → 音高
左右 → 整体音量（不再管发音）

音阶：七声照谱弹得全；五声去掉 4 和 7，
随便弹不难听，但欢乐颂的 4 会被推到旁边
吸附只在音头那一刻起作用 —— 它是帮你打中音的，
不是用来把滑音切成台阶的

左手 · 打击乐（屏幕左半边）
上下移动 → 档位：手在哪一格就是哪一档，
游标跟着手走，看着它移到位
把手放下 → 冻结：档位和音量都保持，
鼓照常走，不用一直举着
要改档位就再抬手。0 到 5 档
静音＝把手瞄到最下面那一格（它一直延伸到
音高场底边，比别的档还宽一点）
手垂到场外＝保持，不是静音 —— 不操作的时候
手放下，鼓照常走。游标这时候画虚线并写明
换档在下一拍生效（约半秒）
左右 → 音量，往左变大，收到最内侧静音
拇指张开 → 速度：八档，80 到 150 BPM。
跨过档的边界就立刻换，不用停、不用等拍。
握拳时速度冻结（握拳拇指是收着的）

转盘平时淡淡地跟着左手走
握拳 → 盘定住，这时候移动手就是在选
上＝手碟　右＝卡林巴　下＝木琴　左＝玻璃
推到哪个方向就用那个音色发一声，听得见再定
推过去就立刻生效，松开拳头 → 定下
不想改就不推，手停在中间，松开即可
握拳期间档位冻结，松开后手上下挪过半档就交还给手

音色只管特雷门琴，和鼓无关。
右手不在画面里时特雷门琴是静音的，
这时候选音色听不见（盘上会提示）
音色写在旋律那根竹的右上角，速度写在左竹竿顶上。改设置用转盘或这里

启动：点一次「开启摄像头」。那一下同时
解锁声音和请求摄像头授权，不用再点第二次。

必须用 localhost 打开。双击文件夹里的
「启动.command」。浏览器禁止 file:// 页面
使用摄像头，双击 html 打开一定没有手势。

节奏密度：骨架 / 稀 / 中 / 满。
抽的是弱拍，切分留在原处，所以每一档
听上去都还是桑巴，不是另一套节奏。

两手向外张开＝一起变大，向内收拢＝一起变小
两只手互不依赖，各自都能单独发声

照谱子弹：谱上写 3，就找标着 3 的那条线。
吸附 100% 时音只会落在这七条线上，
线之间的滑音仍然保留。
